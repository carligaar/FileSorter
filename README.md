# FileSorter

Organizes the files in a selected folder by file extension and creation year, so everything stays tidy and easy to find.

## What it does
- Scans a folder you choose
- Sorts files into subfolders by type and by the year they were created

## Tech
C# (.NET)

## Run it
Clone the repo and open it in Visual Studio, or run `dotnet build` from the project folder.
